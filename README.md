# 마인 팩토리 (MineFactory)

캐고 · 만들고 · 자동화해서 · 화성까지.
나무를 베는 것에서 시작해 공장을 세우고, 마지막에는 로켓을 타고 화성에 정착하는 것이 목표인 2D 도트 샌드박스 게임입니다.

**▶ 바로 플레이: <https://geonhee15.github.io/MineFactory/>** (설치 없이 브라우저에서)

> 현재 버전 **v0.16.0 — 지상과 지하, 동물, 공장의 시작(컨베이어 벨트 · 압축기), 멀티플레이**. 채굴기 · 전기와 우주는 다음 단계에서 만듭니다.

## 실행

빌드 과정도, 설치할 패키지도 없습니다. 정적 파일 서버만 있으면 됩니다.

```bash
npm run dev
```

브라우저에서 <http://localhost:5173> 을 엽니다. (Node가 없다면 `python3 -m http.server 5173` 도 됩니다.)
주소 뒤에 `?slot=test` 처럼 붙이면 다른 저장 칸을 써서, 실제 저장을 건드리지 않고 시험해 볼 수 있습니다.
`?net=local` 을 붙이면 같은 브라우저의 탭끼리만 연결되어, 인터넷 없이 멀티플레이를 시험할 수 있습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `W A S D` / 방향키 | 이동 |
| 좌클릭 (길게) | 캐기 · 베기 · 동물 때리기 / 들고 있는 것 놓기 · 심기 · 밭 갈기 · 길 다지기 |
| 우클릭 | 사용하기 (제작대 · 화로 · 압축기 · 상자 · 동굴 · 열매 따기 · 문 · 울타리 문 · 침대 · 표지판) / 먹기 |
| `R` | 가리킨 설치물을 시계 방향으로 90도 돌리기 (설치물을 들고 빈 칸을 가리키면 놓을 방향) |
| `1`~`9`, 마우스 휠 | 단축바 선택 |
| `E` / `Tab` | 가방과 제작 |
| `M` | 지도 |
| `Q` | 들고 있는 아이템 하나 버리기 |
| `Space` / `F` | 바라보는 칸 캐기 / 사용하기 (키보드만으로) |
| `-` / `=` | 화면 축소 / 확대 |
| `Enter` | 대화 (멀티플레이 중) |
| `Esc` | 창 닫기 · 메뉴 (저장, 멀티플레이, 세이브 관리, 볼륨) |

타이틀 화면에서는 세계를 여러 개 만들어 이름을 붙이고, **세계 목록**에서 골라 플레이합니다.

## 지금 들어 있는 것

- **지상** 512×512 타일의 섬: 초원 · 숲 · 사막 · 바위 지대 · 호수, 참나무/소나무/자작나무/사과나무, 산딸기 덤불, 꽃, 버섯, 야생 당근
- **지하** 512×512 타일의 동굴: 돌 · 안산암 · 화강암 · 석탄 · 철 · 구리 · 금 · 수정, 지하 호수, 빛버섯. 지상 곳곳의 동굴 입구(15개)로 드나듭니다
- 도구 등급(나무 → 돌 → 철), 제작대, 화로(제련 · 굽기), 상자, 횃불, 벽 · 바닥 · 문 · 침대
- 집 짓기: 벽 · 바닥 · 문 위에 **지붕**을 덮으면 밖에서는 안이 보이지 않고, 문을 열거나 안에 들어가면 지붕이 비쳐 보입니다. 지붕을 들고 있는 동안에는 클릭(끌기)으로 덮거나 걷어 냅니다
- **깃발**: 세우고 8가지 색 중 하나를 고르면 미니맵과 지도에 깃발로 표시되고, 멀어지면 미니맵 가장자리의 화살표가 방향을 알려 줍니다
- **삽과 길**: 삽을 들고 풀밭 · 흙 · 모래 · 자갈을 누르면(누른 채 끌면 이어서) 땅이 다져져 길이 됩니다. 길을 다시 누르면 흙으로 돌아가고, 길은 미니맵과 지도에도 보입니다. 길 위에서는 걸음이 조금 빨라집니다
- **동물**: 풀밭에 소 · 돼지 · 양 · 닭이 무리 지어 돌아다닙니다. 마우스로 가리키고 누르면 때리고, 맞은 동물은 달아납니다. 잡으면 소는 소고기와 가죽, 돼지는 돼지고기, 양은 양고기와 양털, 닭은 닭고기 · 깃털 · 달걀을 떨어뜨립니다 (가죽 · 양털 · 깃털 · 달걀은 확률). 가죽은 컨베이어 벨트에, 양털은 양모 침대에 쓰고, 고기는 아직 먹을 수 없습니다. 좋아하는 먹이를 손에 들고 가까이 가면 따라옵니다 — 당근은 돼지, 씨앗은 닭, 밀은 소와 양. 울타리 안으로 데려가 가둘 때 쓰세요
- **검**(나무 · 돌 · 철): 동물을 사냥하는 무기. 맨손이나 다른 도구보다 훨씬 셉니다
- **울타리와 울타리 문**: 울타리는 나란히 놓으면 이어지고, 사람도 동물도 넘지 못합니다. 울타리 문은 우클릭으로 사람만 여닫을 수 있어, 동물을 가둬 둘 수 있습니다
- **양모 침대**(판자 6 + 양털 3): 자고 일어나면 포만감이 가득 찹니다. 낮에 누우면 다음 날 아침이 아니라 그날 저녁 7시까지만 자는 낮잠이 됩니다
- **돌리기**: 제작대 · 화로 · 압축기 · 상자 · 문 · 침대 · 표지판 · 울타리 문 · 나무 벽 · 돌 벽돌 · 컨베이어 벨트는 가리키고 `R`을 누를 때마다 시계 방향으로 90도씩 돕니다. 들고 있을 때 `R`을 누르면 놓을 방향이 미리 돌아갑니다
- **표지판**(판자 3 + 막대기 1 → 2개): 빈 땅에 세우면 표지판, 블록(벽 · 상자 · 나무 · 바위…)에 대고 놓으면 그 블록에 나무 판으로 붙습니다. 4줄 × 14자까지 글을 쓸 수 있고, 가까이 가거나 가리키면 글이 보입니다. 붙인 판은 길게 눌러 먼저 떼어 낼 수 있습니다
- **큰 상자**: 상자 두 개를 나란히(좌우 또는 위아래) 놓으면 54칸짜리 큰 상자가 됩니다. 한쪽을 부수면 그쪽 27칸의 물건만 쏟아지고 남은 쪽은 보통 상자로 돌아갑니다
- **그로기와 리스폰**: 포만감이 0이 되면 그로기 상태가 되어 기어가듯 느려지고, 2분 안에 아무것도 먹지 못하면 쓰러집니다. 쓰러지면 가방의 물건을 그 자리에 모두 쏟고, 리스폰 지점(우클릭해 둔 침대)이나 처음 시작한 자리에서 포만감 50으로 다시 일어납니다
- **컨베이어 벨트**(철 주괴 1 + 톱니바퀴 1 + 풀섬유 6 → 4개, 가죽 2를 쓰면 8개): 놓인 방향으로 그 위의 아이템을 실어 나릅니다. 앞에 붙은 상자 · 화로 · 압축기에는 물건을 넣고(재료는 재료 칸, 연료는 연료 칸), 뒤에 붙은 상자 · 기계에서는 1초에 하나씩 꺼냅니다(기계는 결과 칸에서만). 벨트 위의 물건은 끌려오지 않아서, 직접 밟아야 주울 수 있습니다
- **압축기**(기계 틀 1 + 피스톤 1 + 톱니바퀴 2 + 구리선 4 + 화로 1): 연료를 태워 재료 3개를 판 하나로 누릅니다 — 화강암 판 · 안산암 판 · 철판 · 금 판 · 구리 판. 기계 틀은 철 주괴 4 + 돌 벽돌 2, 피스톤은 철 주괴 2 + 막대기 2
- 가리킨 것의 이름: 마우스로 가리킨 블록 · 떨어진 아이템 · 땅의 이름과 그림이 화면 오른쪽 아래에 작게 나옵니다
- 농사: 괭이로 밭을 갈고 밀 · 당근 재배 (물가 근처에서 더 빨리 자람), 묘목과 덤불 옮겨 심기
- 낮과 밤, 조명, 포만감, 미니맵과 탐험 지도, 목표(튜토리얼), 자동 저장
- **멀티플레이**(최대 8명), **세계 여러 개**와 **세이브 보호**(세계별 자동 백업 · 파일 내보내기) — 아래 참고

## 멀티플레이

서버 없이 브라우저끼리 직접 연결합니다(WebRTC).

1. 방장: 게임 중 `Esc` → **멀티플레이** → **방 열기**. 6글자 방 코드와 초대 링크가 나옵니다.
2. 친구: 타이틀 화면의 **친구 방에 참가**에 코드를 넣거나, 초대 링크(`…/?join=코드`)를 엽니다.

- 세계는 방장의 것이고 방장 기기에 저장됩니다. 방장이 게임을 닫으면 방도 닫힙니다.
- 손님의 가방 · 진행도 · 지도는 손님 브라우저에 세계별로 저장되어, 같은 세계에 다시 들어오면 이어집니다.
- 상자 · 화로 · 압축기는 한 번에 한 사람만 열 수 있고(큰 상자는 두 칸을 함께), 잠이나 낮잠으로 시간을 넘기는 것은 방장만 할 수 있습니다.
- 표지판 글 · 블록의 방향 · 컨베이어 벨트도 모두에게 똑같이 보입니다. 벨트가 물건을 넣고 꺼내는 일은 방장 쪽에서 처리합니다.
- 동물은 방장 쪽에서 움직이고, 손님에게는 가까이 있는 동물만 보입니다.
- 연결 중계(시그널링)는 [PeerJS](https://peerjs.com)의 공개 서버를 씁니다. 회사 · 학교 같은 일부 네트워크에서는 직접 연결이 막힐 수 있습니다.

## 세이브

세이브는 쿠키가 아니라 브라우저의 IndexedDB에 **세계마다 따로** 저장됩니다.

- **세계 여러 개**: 타이틀 화면의 **새 세계 만들기**에서 이름(과 원하면 시드)을 정해 만들고, **세계 목록**에서 골라 플레이합니다. 새 세계를 만들어도 다른 세계는 그대로 남습니다. 예전 버전에서 하던 세계는 '나의 첫 세계'라는 이름으로 목록에 그대로 올라옵니다.
- **세이브 관리**: 세계 목록의 **관리**(플레이 중에는 `Esc` → **세이브 관리**)에서 세계 이름 바꾸기, 백업으로 되돌리기, 파일로 내보내기, 세계 지우기(타이틀 화면에서만)를 합니다.
- **자동 백업**: 세계마다 10분마다, 그리고 되돌리기 직전에 만들어 최근 6개를 보관합니다. 언제든 되돌릴 수 있습니다.
- **파일로 내보내기 / 불러오기**: 세계 전체를 `.mfsave` 파일(약 100~200KB)로 받아 두고, 어느 컴퓨터 · 브라우저에서든 세계 목록에서 다시 불러옵니다. 불러온 파일은 새 세계로 더해지고 다른 세계를 덮어쓰지 않습니다.
- 브라우저의 사이트 데이터를 지우면 세이브와 백업이 함께 사라지므로, 아끼는 세계는 파일로 내보내 두는 것이 가장 안전합니다. (서버 저장은 아직 없습니다.)

## 만든 방식

- **그래픽**: 이미지 파일이 하나도 없습니다. 모든 도트는 [`src/gfx/sprites.js`](src/gfx/sprites.js) 와 [`src/gfx/sprites_items.js`](src/gfx/sprites_items.js) 에서 코드로 그려 아틀라스로 만듭니다. `tools/atlas.html` 에서 전체 스프라이트를 볼 수 있습니다.
- **소리**: 음원 파일도 없습니다. 효과음 · 환경음 · 배경음악을 모두 [`src/audio.js`](src/audio.js) 에서 WebAudio로 합성하며, 배경음악은 낮 · 밤 · 동굴 분위기에 맞춰 매번 새로 작곡됩니다.
- **엔진**: 빌드 없는 순수 JavaScript(ES 모듈) + Canvas 2D. 저장은 IndexedDB. 멀티플레이를 쓸 때만 PeerJS를 CDN에서 불러옵니다.

```
src/
  main.js            진입점, 메인 루프
  game.js            게임 규칙 (이동, 채굴, 설치 · 돌리기, 표지판, 큰 상자, 컨베이어 벨트, 화로 · 압축기, 포만감과 리스폰)
  mobs.js            동물 (돌아다니기, 달아나기, 드롭, 멀티플레이 동기화)
  ui.js              HUD · 가방 · 제작 · 지도 · 메뉴 (한국어)
  audio.js           효과음 · 환경음 · 자동 작곡 배경음악
  net.js             멀티플레이 (방장-손님 구조, WebRTC)
  save.js            세계 목록 · 저장 · 세계별 자동 백업 · 세이브 파일
  world/gen.js       지상 · 지하 월드 생성
  world/world.js     타일 데이터
  gfx/               도트 생성기와 렌더러
  data/              지형 · 오브젝트 · 아이템 · 레시피 · 동물 정의
```
